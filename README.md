# Rollo front-admin

Panel de administración de Rollo (Next.js App Router, shadcn/ui, Tailwind). Habla con el backend de Cloudflare Workers a través de un BFF del lado del servidor.

## Desarrollo

```bash
cp .env.example .env.local   # BACKEND_URL=http://localhost:8787
npm install
npm run dev
npm test
npm run build
```
